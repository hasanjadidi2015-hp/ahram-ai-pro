# AHRAM AI — ربات نوسان‌گیری اپشن بورس ایران

## نصب:
1. Python 3.11 نصب کن
2. pip install -r requirements.txt
3. python agent.py (تست)
4. start.bat (اجرای خودکار)

## نمادها:
اهرم + وبملت + شستا

## ساعات بازار:
شنبه تا چهارشنبه، ۹:۰۰ تا ۱۲:۳۰

## فایل‌های اصلی:
- agent.py — ایجنت اصلی
- strategy.py — استراتژی ۷ اندیکاتور
- queue_surge.py — تشخیص صف سنگین
- option_engine.py — بلک‌شولز + Greeks
- config.py — تنظیمات
